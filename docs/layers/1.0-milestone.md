# Layer 1.0 — Integration milestone

**Status:** landed on `main` (tag `v1.0.0`)  
**Depends on:** cumulative layers 0.1–0.9

## Goal

Declare a **stable product surface** for the userspace OMLS stack: one version string (`1.0.0`), an end-to-end smoke path, and a clear boundary between shipped layers and research/future work.

## What 1.0 is

The cumulative functional stack on `main`:

| Layer | Capability |
|---|---|
| 0.1 | Discover → RDL Machine Profile |
| 0.2 | Fabric (gRPC + mTLS) + Resource Graph |
| 0.3 | Scheduler + EWMA learning + `run-demo` |
| 0.4 | Resource Envelopes (ADSR) |
| 0.5 | Behavior Profiles + telemetry persistence |
| 0.6 | Adaptive multi-signal scheduling + hysteresis |
| 0.7 | Community hardware profile priors |
| 0.8 | VFIO/UIO sandbox probe (dry-run claim) |
| 0.9 | Power Fabric MCU simulator + envelope budgets |

Version string: CLI `omls version` and fabric `Health.version` report **`1.0.0`**.

## Smoke coverage

`TestStackSmoke1_0` (in-process, no multi-host) exercises:

```text
RDL advertise → community prior → sandbox merge → heartbeat →
envelope + power budget → adaptive run-demo → behavior persist → graph dump
```

## Still research / future (not required for 1.0)

| Topic | Status |
|---|---|
| Cross-ISA process migration (Popcorn-like) | Research track only |
| Real MCU / protected power switching | Beyond 0.9 simulator |
| Language Plane / Ollama local LLM | Documented future — no hard dependency |
| Real VFIO bind / IOMMU driver sandbox | Beyond 0.8 stub |
| Kernel hooks / eBPF / Linux fork | Only if userspace proves insufficient |
