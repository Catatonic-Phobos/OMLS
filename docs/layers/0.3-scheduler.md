# Layer 0.3 — Scheduler + Learning Plane (delivered)

**Status:** on `main` as `afb43a5` (`feat(0.3): scheduler, worker pool, and EWMA run-demo`)  
**Depends on:** 0.1 discover/RDL, 0.2 fabric + Resource Graph

## What landed

- **Function request** `parallel_workers` with hard capability filter `compute` + `parallelizable`.
- **Scheduler v0** (`internal/schedule`): score by capacity/load, locality (local hostname preferred), WSL/virt penalty, optional thermal ceiling.
- **Agent worker pool**: agents `ClaimWork` / `ReportWork`; synthetic CPU burn in `internal/work`.
- **Learning Plane v0** (`internal/learn`): EWMA of duration and temp-delta; `Adjust` moves workers for thermal escape or slow-vs-fast duration (>1.25×) with printable reasons.
- **CLI demo:** `omls master run-demo --workers N --iterations M`.

## Demo loop

```text
schedule → enqueue work units → agents burn → observe EWMA → adjust → next round
```

Acceptance observed in lab: with ≥2 heterogeneous agents (or simulated unequal durations), later rounds prefer the faster/cooler node; missing thermal stays neutral.
