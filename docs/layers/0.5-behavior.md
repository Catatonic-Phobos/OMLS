# Layer 0.5 — Behavior Profiles + telemetry persistence

**Status:** landed on branch `cursor/omls-0.5-behavior-3385` (PR → `main`)  
**Depends on:** 0.2 heartbeats/telemetry, 0.3 learning observations

## Goal

Make observed node behavior durable across master restarts so the Learning Plane can seed from disk instead of starting cold every demo.

## What this layer owns

- **Behavior Profile** YAML per node under `--data-dir/profiles/` (EWMA duration/temp-delta, confidence, recent telemetry ring).
- **Telemetry history** JSONL under `--data-dir/telemetry/`.
- Heartbeat / stream telemetry → `RecordTelemetry`.
- Demo rounds → `ObserveWork`; next `RunDemo` → `learn.Seed` from store.
- RPCs: `ListProfiles`, `GetProfile`.
- CLI: `omls master serve --data-dir`, `omls master profiles list|show`.

## Boundaries

| In 0.5 | Deferred |
|---|---|
| Disk prior for EWMA stats | Adaptive scheduling beyond stats → **0.6** |
| Per-node confidence curve | Community hardware profiles → **0.7** |
